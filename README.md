# Rename the Planet

A make.fun bounty entry: one funny line that gives Earth a new name and says why, in a single line under 200 characters. The joke works by treating the whole planet as the one group project everyone has lived through — eight billion people turn up, almost nobody does the work, and the one species actually keeping everything running gets no credit.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
